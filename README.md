# Distributor Sales Report Generator

## Overview

A Python application that generates professional monthly distributor performance scorecards in PDF format from Excel data.

## Features

- Read distributor performance from Excel
- Generate individual PDF reports
- Modern HTML/CSS template
- Financial year (April–March) support
- Automatic handling of missing months
- Company branding support
- Batch PDF generation

## Technology Stack

- Python
- Pandas
- Jinja2
- HTML5
- CSS3
- WeasyPrint
